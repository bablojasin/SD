# SPECTRE DEFEND Performance Budget

## Purpose & Enforcement
To maintain exceptional loading speeds, low bandwidth usage, and high Core Web Vitals rankings on both mobile and desktop devices, **SPECTRE DEFEND** enforces the following performance budgets.

---

## 1. Network Payload Budgets (Gzipped & Transferred)

| Asset Type | Maximum Budget (Target) | Current Production Value | Status |
| :--- | :--- | :--- | :--- |
| **Initial HTML** | < 15 KB | ~3.8 KB | **PASS** (Well under budget) |
| **Critical CSS** | < 25 KB gzipped | ~13.2 KB gzipped | **PASS** (47% headroom) |
| **Main JS Bundle** | < 150 KB gzipped | ~127.4 KB gzipped | **PASS** (15% headroom) |
| **Total Initial JS** | < 250 KB gzipped | ~185.0 KB gzipped | **PASS** (Route-split) |
| **Critical LCP Image (Mobile)** | < 35 KB | 18.1 KB (`480w.webp`) | **PASS** (48% headroom) |
| **Critical LCP Image (Desktop)** | < 100 KB | 78.5 KB (`1200w.webp`)| **PASS** (21% headroom) |
| **Total First Viewport Payload** | < 400 KB | ~280 KB (Desktop) / ~160 KB (Mobile) | **PASS** |
| **Web Fonts** | < 60 KB total | Loaded with `font-display: swap` & DNS preconnect | **PASS** |

## 2. Timing & Core Web Vitals Thresholds

| Metric | Target (Good) | Needs Improvement | Critical Limit | SPECTRE DEFEND Target |
| :--- | :--- | :--- | :--- | :--- |
| **Largest Contentful Paint (LCP)** | ≤ 1.2s (Desktop) / ≤ 1.8s (Mobile) | > 2.0s | > 2.5s | **~0.9s - 1.2s** |
| **Cumulative Layout Shift (CLS)** | ≤ 0.05 | > 0.10 | > 0.25 | **0.00** |
| **First Contentful Paint (FCP)** | ≤ 0.8s | > 1.8s | > 3.0s | **~0.6s** |
| **Interaction to Next Paint (INP)**| ≤ 100ms | > 200ms | > 500ms | **< 60ms** |
| **Total Blocking Time (TBT)** | ≤ 150ms | > 300ms | > 600ms | **< 80ms** |

---

## 3. Enforcement Strategy in CI/CD
1. **Build Gate**: `npm run build` generates production assets into `dist/`. Vite chunk size warning limit is set to `600 KB` uncompressed.
2. **Chunk Splitting**: Vendor dependencies (`vendor-react`, `vendor-icons`, `vendor-motion`) are isolated into cached chunks, allowing browsers to persist libraries across deploys.
3. **Route Splitting**: Non-essential pages (`/about`, `/services`, `/team`, `/blog`, `/contact`, `/privacy`) are loaded as asynchronous chunks upon route navigation.
4. **Media Verification**: All raster assets in `public/images/` must have companion responsive `.webp` variants generated by `scripts/optimize-images.mjs`.
